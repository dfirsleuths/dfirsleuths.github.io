# Narcos - DFIR Sleuths

A digital forensics scenario for Digital Corpora

A digital forensics training scenario built by the DFIR Sleuths team as a group project for the Wellington Institute of Technology (WelTec).

The project set out to create a plausible, self-contained case so forensics students had realistic material to work with. The scenario follows an international drug-smuggling investigation across three suspect devices, each running a different Windows 10 build.

The scenario is published on Digital Corpora as the 2019 Narcos scenario:
https://digitalcorpora.org/corpora/scenarios/2019-narcos/

## The site

This repo is the project's site, live at https://dfirsleuths.github.io/. It covers the scenario, the methodology used to build it, the testing process, the team, and the tools used.

It's a hand-built static site: plain HTML and CSS with a small amount of JavaScript for the tool-screenshot lightbox. No framework and no build step. It deploys from the repo root via GitHub Pages.

## Structure

- `index.html` - home, team, project links, tools
- `scenario.html` - the case scenario
- `methodology.html` - how the scenario was built
- `testing.html` - the testing approach
- `assets/` - styles, script, images
